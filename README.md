# xingyao-perf

机械革命星耀14（`XINGYAO Series-P916F-PTL`，Core Ultra X7 358H）的极简性能工具：托盘切换性能模式，并在任务栏上直接显示监控数值。

当前版本 0.9.5。单个 exe，约 70 KB，依赖系统自带的 .NET Framework。

## 功能

- **模式切换：** 办公、平衡、性能。托盘图标用三根递增的条显示当前模式，切换后会回读确认。
- **任务栏监控：** 用带数值的颜色条显示 CPU 和 GPU 占用、P / E / LPE 核平均频率、CPU 封装功耗和温度、GPU 频率和功耗、两个风扇转速，按列对齐。全屏应用时自动隐藏。
- **恢复模式：** 启动或唤醒后 60 秒内，把模式恢复成上次的选择。之后由 Fn 键等改动的模式会被记住。
- **CPU / GPU 最高频率：** 用来在 CPU 和核显之间分配共用的封装功耗。CPU 用电源计划的“最大处理器状态”，可选不限制、关闭睿频（约 1.8 GHz）、约 1.5 GHz、约 1.3 GHz，P 核和 E 核一起，插电和电池都生效；更高的中间值做不到，因为频率上限会被 Intel 的服务改写。GPU 上限通过 Intel 显卡库设置，可选 2.0 到 0.9 GHz（驱动不允许低于 0.9），驱动不允许时菜单变灰。
- **风扇：** 自动（EC 曲线）、静音或手动 30% / 50% / 70% / 100%。EC 会自己保持手动转速，不需要重发；温度到 85 °C 或读不到温度、睡眠、退出时交还 EC；每次启动都从自动开始，手动档位不保存。实测 50% 约 5250 rpm，70% 约 6500 rpm，100% 约 8200 rpm。静音模式：最近 30 秒的平均温度不超过 50 °C、平均封装功耗不超过 13 W 时停转（`D6 00`）；最近 5 秒平均温度到 55 °C、单次到 75 °C、功耗连续 2 秒到 15 W、读不到温度、采样卡住 5 秒、睡眠或退出时交还 EC。静音模式会保存，重启后从 EC 曲线开始。
- **充电上限：** 菜单里可设 60%、80% 或关闭。设置存在 EC 里，关机和重启后都保持，程序不运行也有效。只有 80% 在本机实测过。
- **开机启动：** 通过提权的计划任务实现，不弹 UAC。
- **任务栏嵌入：** 监控条是任务栏的子窗口，打开开始菜单时不会被盖住。嵌入失败时自动退回悬浮窗口，并写入日志。
- **避让天气：** 任务栏图标左对齐时，系统的天气按钮在托盘旁边，监控条会停在它左边。样式为自动时按读到的按钮实际位置避让，否则按固定宽度预留。
- **监控条样式：** 完整版、精简版（去掉 E / LPE 频率和风扇）或自动。自动时每 3 秒用 UI Automation 读一次任务栏按钮占到哪里，放得下完整版就用完整版，内存多约 10 MB；选完整版或精简版时不读取。

- **游戏和全屏时显示：** 可选关闭、仅游戏（自动识别）、所有全屏程序和游戏。游戏按 Windows 自己记录的游戏列表（游戏栏和游戏模式用的那份，注册表 `HKCU\System\GameConfigStore\Children`）自动识别，英雄联盟客户端、Steam、Epic 等启动器除外。在游戏或全屏窗口左上角显示半透明、鼠标可点穿的完整版监控条，切走后隐藏。不注入游戏进程，不影响反作弊；真正的独占全屏可能盖住它。Windows 没识别的游戏，可以加在 `settings.ini` 的 `games=` 里，写进程名，不带 `.exe`，多个用 `|` 分隔。

左键或右键点击托盘图标或监控条都能打开菜单。

## 构建和运行

```powershell
.\build.ps1
.\dist\xingyao-perf.exe
```

构建使用 Windows 自带的 `csc.exe`，不需要 SDK。程序需要管理员权限，没有计划任务时会弹一次 UAC。

| 参数 | 作用 |
|---|---|
| `--no-gpu` | 不读 GPU 频率，常驻内存从约 70 MB 降到约 27 MB |
| `--no-elevate` | 不请求管理员权限，模式和温度不可用 |
| `--selftest <文件>` | 读取一遍所有数据并写入文件，不做任何写入 |

设置和日志在 `%LOCALAPPDATA%\xingyao-perf`。

## 风险提示

模式切换使用未公开的固件接口，只在 BIOS 1.00 和 1.01 上放行。其他 BIOS 或机型会自动禁用切换，只保留监控。BIOS 升级后需要重新验证。

官方控制中心不知道这里的切换，它的界面可能显示旧模式。

## 其他内容

- `scripts/`：验证和测试脚本，`-Load cpu|gpu|both` 选择负载，`-Mode keep` 时不写入。
- `tools/`：只读的分析和摸底脚本。
- [docs/protocol.md](docs/protocol.md)：协议和验证记录。
