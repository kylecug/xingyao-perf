# xingyao-perf

机械革命星耀14（`XINGYAO Series-P916F-PTL`，Core Ultra X7 358H）的极简性能工具：托盘切换性能模式，并在任务栏上直接显示监控数值。

当前版本 0.9.28。单个 exe，约 100 KB，依赖系统自带的 .NET Framework。

## 功能

- **模式（托盘菜单第一组，八选一，会保存）：** “官方模式”子菜单里是办公、平衡、性能，选中后 Windows 电源模式改回“平衡”，不限 CPU / GPU，风扇用 EC 曲线。下面是五个自定义模式，菜单上显示为“自定义：名字”：点名字切换，鼠标停在上面弹出“设置…”。每个自定义模式可以设名称、官方模式、Windows 电源模式（最佳能效 / 平衡 / 最佳性能）、CPU 和 GPU 最高频率和风扇曲线。默认第一个是“日常静音模式”（官方办公模式＋最佳能效＋GPU 限 1.2 GHz，风扇 62 °C 以下停转、62 °C 起 10%、68 °C 起 20%、74 °C 起交还 EC），第二个是“火力全开模式”（官方性能模式＋最佳性能，风扇全程 EC），其余是“模式 3”到“模式 5”。风扇曲线有四个温度点：最低温以下和每个点起各一档转速（停转、10–100% 或 EC），最后一个点起交还 EC；按 5 秒平均温度升档，降温要低于该点 3 °C 并保持 20 秒才降档，单次读数超过最后一个点 5 °C、读不到温度、睡眠或退出时交还 EC。选任何一个模式，风扇、CPU、GPU 菜单都回到“自动”。按 Fn 键切换官方模式时，当作选了对应的官方模式。托盘图标用三根递增的条显示当前官方模式，切换后会回读确认。
- **任务栏监控：** 每个框都是像任务管理器那样的约 1 分钟时间曲线，按当时的数值分段显示绿 / 橙 / 红：CPU 和 GPU 占用、P / E / LPE 核平均频率、GPU 频率、物理内存占用、网络收发、温度、两个风扇转速；框里显示当前数值，功率框显示 CPU 封装功耗和 GPU 功耗（用电池时换成整机功耗，前面加 Σ）。全屏应用时自动隐藏。
- **恢复模式：** 启动或唤醒后 60 秒内，把模式恢复成上次的选择。之后由 Fn 键等改动的模式会被记住。
- **CPU / GPU 最高频率：** 用来在 CPU 和核显之间分配共用的封装功耗。“自动”时官方模式下不限制，自定义模式下用它自己的设置。CPU 用电源计划的“最大处理器状态”，固定档可选关闭睿频（约 1.8 GHz）、约 1.5 GHz、约 1.3 GHz，P 核和 E 核一起，插电和电池都生效；更高的中间值做不到，因为频率上限会被 Intel 的服务改写。GPU 上限通过 Intel 显卡库设置，固定档可选 2.0 到 0.9 GHz（驱动不允许低于 0.9），驱动不允许时菜单变灰。
- **风扇：** 自动（跟随模式：官方模式用 EC 曲线，自定义模式用它自己的设置）、EC 曲线或手动 10% / 20% / 30% / 50% / 70% / 100%。EC 会自己保持手动转速，不需要重发；温度到 85 °C 或读不到温度、睡眠、退出时交还；每次启动都从自动开始，手动档位不保存。实测 10% 约 1175 rpm，20% 约 2520 rpm，30% 约 3530 rpm，50% 约 5250 rpm，70% 约 6500 rpm，100% 约 8200 rpm。自定义模式的风扇曲线还会在采样卡住 5 秒时交还 EC。
- **充电上限：** 菜单里可设 60%、80% 或关闭。设置存在 EC 里，关机和重启后都保持，程序不运行也有效。只有 80% 在本机实测过。
- **开机启动：** 通过提权的计划任务实现，不弹 UAC。
- **任务栏嵌入：** 监控条是任务栏的子窗口，打开开始菜单时不会被盖住。嵌入失败时自动退回悬浮窗口，并写入日志。
- **避让天气：** 任务栏图标左对齐时，系统的天气按钮在托盘旁边，监控条会停在它左边。样式为自动时按读到的按钮实际位置避让，否则按固定宽度预留。
- **监控条样式：** 完整版、精简版（去掉文字标签、E / LPE 频率；温度和两个风扇的平均转速上下排列）或自动。自动时每 3 秒用 UI Automation 读一次任务栏按钮占到哪里，放得下完整版就用完整版，内存多约 10 MB；选完整版或精简版时不读取。

- **游戏和全屏时显示：** 可选关闭、仅游戏（自动识别）、所有全屏程序和游戏。游戏按 Windows 自己记录的游戏列表（游戏栏和游戏模式用的那份，注册表 `HKCU\System\GameConfigStore\Children`）自动识别，英雄联盟客户端、Steam、Epic 等启动器除外。在游戏或全屏窗口左上角显示半透明、鼠标可点穿的帧数和完整版监控条，切走后隐藏。帧数来自 Windows 自带的 DXGI Present 事件（ETW，和 PresentMon 同一方法），只支持 Direct3D 10–12，Vulkan / OpenGL 显示 `--`，只在监控层显示时统计。不注入游戏进程，不影响反作弊；真正的独占全屏可能盖住它。Windows 没识别的游戏，可以加在 `settings.ini` 的 `games=` 里，写进程名，不带 `.exe`，多个用 `|` 分隔。

- **桌面小屏：** 每次采样后把监控数据用 UDP 发一个包到端口 4210，由桌面小屏显示 CPU、GPU、温度、功耗、风扇、内存、网络和当前模式名：ESP32-C3 小屏 HW-675（固件在 `esp32c3-oled` 项目）和 T-Display（固件在 `esp32-tdisplay` 项目）。默认 `settings.ini` 里 `esp=broadcast`：在家里局域网广播，几块小屏同时都能收到，不用填地址（每 30 秒在后台重新看一次网卡，换网络也能跟上）。也可以填一个主机名或 IP 只发给那一台；留空就不发。只读不写，不影响采样。少数路由器会拦广播包（“广播/组播隔离”或 AP 隔离），那样就改填小屏的地址。

左键或右键点击托盘图标或监控条都能打开菜单。

## 构建和运行

```powershell
.\build.ps1
.\dist\xingyao-perf.exe
```

构建使用 Windows 自带的 `csc.exe`，不需要 SDK。程序需要管理员权限，没有计划任务时会弹一次 UAC。

| 参数 | 作用 |
|---|---|
| `--no-gpu` | 不读 GPU 频率，常驻内存从约 70 MB 降到约 27 MB |
| `--no-elevate` | 不请求管理员权限，模式和温度不可用 |
| `--selftest <文件>` | 读取一遍所有数据并写入文件，不做任何写入 |

设置和日志在 `%LOCALAPPDATA%\xingyao-perf`。

## 风险提示

模式切换使用未公开的固件接口，只在 BIOS 1.00 和 1.01 上放行。其他 BIOS 或机型会自动禁用切换，只保留监控。BIOS 升级后需要重新验证。

官方控制中心不知道这里的切换，它的界面可能显示旧模式。
